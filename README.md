# Pingyi Miao · Academic homepage

Personal academic homepage for **Pingyi Miao**, built as a responsive, accessible static page for GitHub Pages.

**Website:** https://miaopingyi.github.io/

## Edit and preview

All homepage content and styles are in `index.html`. No package installation or build is required.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Visit http://127.0.0.1:8000/. GitHub Pages should serve the root of `main`. The existing `.nojekyll` enables plain static hosting.
